# playOnline

Simple Vite + React project with two routes and a header + left sidebar menus.

Run locally:

```bash
cd playOnline
npm install
npm run dev
```

Files of interest:
- `src/App.jsx` - main layout and routes
- `src/components/Header.jsx` - top header menu
- `src/components/Sidebar.jsx` - left menu that changes per top route
